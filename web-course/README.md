# Вебкурс — версія для розробки

Підготовлений інтерфейс 13-сторінкового мікрокурсу: інтро з відео, персоналізація, AI-помічники, художня студія, окремий ігровий зал та завершення «Від авторів».

## Нова збірка — очікує мобільного перегляду

Оновлення зібрані та перевірені локально; вихідний код підготовлено для гілки `developer`. Деплой і завантаження нової версії у Cloudflare не виконувалися. Поточний живий сайт лишається на версії, зазначеній у `deployment-status.json`; його поле `prepared_release` описує цей неопублікований пакет.

Пакет для наступної публікації: `ainarium-cloudflare-ready-for-mobile-review.zip`. У ньому є `public`, незмінений `worker.mjs`, конфігурація пошти та захисту, локальний сервер, перевірки й звіт `release-preflight.json`. Секрети залишаються у Cloudflare. Публікувати тільки після мобільного перегляду власником і його подальшої команди.

Перша сцена відкриває аерохокей у тому самому вікні; у грі є «Перезапустити». Початковий шоурум має художню студію, E-Tech і Git Kindergarden. Наступний екран — окремий ігровий зал із п’ятьма іграми, включно з «Мавпячим переполохом». Галерея вміє відкривати малювання й додавати готову роботу на активну дошку. Майстерня спочатку показує простий режим; усі інструменти відкриваються кнопкою «Справжній художник».

Локальний перегляд, який уже запущено для власника: `http://127.0.0.1:8894/`. Його джерело — `outputs/ainarium-creative-workshop/public`. Воно звірене з цією папкою `public` за всіма 92 файлами. Якщо після мобільного перегляду будуть нові правки, їх потрібно повторно перенести сюди й оновити архів та маніфест.

Перевірки: `python verify.py` та `node --test feedback.test.mjs tests/arcade.test.mjs tests/hockey-core.test.mjs tests/monkeys-core.test.mjs tests/studio-core.test.mjs`. Пройдено 41 тест, синтаксис 28 публічних сценаріїв і перевірку локальних посилань 15 HTML-сторінок. Wrangler 4.156.0 пройшов `deploy --dry-run` без публікації. Фізичний мобільний пристрій ще очікує перегляду власником; висновок про нього не робився.

## Локальний запуск

З папки `web-course`:

```powershell
python preview.py
```

Відкрити `http://127.0.0.1:8894/index.html`. Завершення доступне за `app.html#authors`.

Сайт не потребує збірки чи сторонніх бібліотек. Зберігайте всю структуру `public`, включно з `assets` та `examples`.

## Поведінка

- Інтро й відеоперехід 1→2 мають плавне згасання звуку та кінематографічне завершення.
- На перших 12 екранах Айная відкриває підказки після натискання. Desktop-навігація залишається в межах вікна.

- На телефоні курс працює як галерея без папкових workflows і копіювання prompts.
- Творча дошка на комп’ютері підтримує власні зображення, колекції й експорт. Роботи зберігаються локально у браузері.
- Завершення містить хлопчика й Айнаю та легку HTML/CSS-анімацію «Людина задумує. AI допомагає втілити.». Репліки повертаються до цієї головної думки; анімацію можна повторити. Reduced motion враховано.

## Приклади в тому самому вікні

Усі три плітки шоуруму відкривають приклад у поточній вкладці на комп’ютері й телефоні. Синя кнопка «До шоуруму» повертає на сторінку курсу з трьома прикладами (`app.html#showroom`). E-Tech показується на `e-tech.html` у вбудованому перегляді з постійною верхньою панеллю; галерея й Git Kindergarden зберігають свої сторінки та інтерактиви. Наявна публікація E-Tech і її домени не змінювалися.

У `_headers` тільки шлях `/e-tech*` дозволяє iframe з точного джерела `https://e-tech-ainarium.pages.dev`. Інші сторінки зберігають попередню політику безпеки. Вбудований приклад працює без дозволу відкривати нові вікна. Перевірено переходи та повернення, мобільний розмір 390×844 і завантаження живого уроку.

## Пошта

Форма «Від авторів» надсилає повідомлення через `POST /api/feedback` у Cloudflare Worker. Отримувач задається серверним секретом `FEEDBACK_TO`; у публічному коді його немає. Відправник — `feedback@ainarium.ai`, наявний домен Email Routing. Тестовий лист прийшов у «Вхідні», що підтвердив власник 2026-10-31.

Обробник перевіряє Origin, тип і розмір запиту та три поля форми. Обмеження — приблизно 5 спроб за хвилину з однієї мережевої адреси в кожній локації Cloudflare. Поштова помилка не показується як успіх; текст лишається у формі. Зміст повідомлень і приватна адреса не записуються у логи обробника.

Для локальної перевірки форми потрібен `npx wrangler@4.156.0 dev`. Звичайний Python-сервер показує лише сайт без поштового API. На іншому Worker перед публікацією потрібно підтвердити отримувача, налаштувати поштовий домен і додати секрет командою `npx wrangler@4.156.0 secret put FEEDBACK_TO`. Не передавайте адресу через публічний конфіг чи коміт.

## Перевірка

```powershell
python verify.py
```

Перевіряє цілісність усіх 92 файлів пакета (91 ресурс сайту та службового `_headers`) за `site-manifest.json`. У браузері перевірено маршрут на ноутбуці й у мобільному режимі, повернення зі збереженням персоналізації, відеоперехід, форму, персонажів і повтор неонової анімації. Фізичні телефони й Safari не тестувалися.

Для наступного деплою є `deploy.ps1 -WorkerName <existing-worker-name>`. Скрипт використовує `wrangler.jsonc` і публікує також поштовий обробник. Не замінюйте цей деплой завантаженням лише статичних файлів, інакше поштовий API зникне. Перевірка обробника: `node --test feedback.test.mjs`.

Авторство та умови використання матеріалів визначені кореневим README цього репозиторію. Ця папка не змінює профільного маніфесту.

## Захист

У Cloudflare увімкнено Always Use HTTPS і мінімальний TLS 1.2; TLS 1.3 вже працював. Домен має блокування перенесення та WHOIS-redaction. Безкоштовні стандартні засоби Cloudflare залишаються активними; платні підписки не додано.

`public/_headers` обмежує сторонні джерела контенту, вбудовування сайту чужими сторінками, доступ до камери, мікрофона, геолокації та платежів. Власний iframe фіналу дозволено. Inline scripts/styles залишені для сумісності чинного курсу; це не повна перебудова захисту від XSS. Зміст приватної пошти й секрети не публікуються. API додатково повертає захисні заголовки для JSON-відповідей.

Після публікації перевірено HTTPS-redirect, заголовки чотирьох сторінок, недоступність `.env`, `.git/config`, серверного коду й конфігурації; API відхиляє чужий Origin, порожні поля та завеликий запит. Вісім перевірок обробника пройдено. Інтро, галерея, Git Kindergarden і iframe фіналу перевірено у браузері.

Мобільний TOTP 2FA активний: статус перевірено у Cloudflare після завершення налаштування власником. DNSSEC активовано власником і підтверджено у Cloudflare та публічним DNS-запитом (authenticated data = true). Certificate Transparency alerts увімкнені, у панелі підтверджено одного активного отримувача; його адреса не публікується. Не зберігайте паролі, TOTP-секрети й recovery codes у репозиторії.

Загальнодоступні матеріали можна завантажувати; ці налаштування не створюють DRM. Репозиторій залишається публічним за рішенням власника.

Для локальної перевірки з поточним емулятором: `npx wrangler@4.156.0 dev --compatibility-date 2026-10-30`; дата робочого Worker лишається 2026-10-31.
