# Вебкурс — версія для розробки

Завершений інтерфейс 12-сторінкового мікрокурсу: інтро з відео, персоналізація, AI-помічники, приклади, творча дошка та завершення «Від авторів».

## Локальний запуск

З папки `web-course`:

```powershell
python -m http.server 8880 --directory public
```

Відкрити `http://127.0.0.1:8880/index.html`. Завершення доступне за `app.html#authors`.

Сайт не потребує збірки чи сторонніх бібліотек. Зберігайте всю структуру `public`, включно з `assets` та `examples`.

## Поведінка

- Інтро й відеоперехід 1→2 мають плавне згасання звуку та кінематографічне завершення.
- На перших 11 екранах Айная відкриває підказки після натискання. Desktop-навігація залишається в межах вікна.
- Вибір імені, стилю та тем зберігається при поверненні із завершення до курсу.
- На телефоні курс працює як галерея без папкових workflows і копіювання prompts.
- Творча дошка на комп’ютері підтримує власні зображення, колекції й експорт. Роботи зберігаються локально у браузері.
- Завершення містить хлопчика й Айнаю та легку HTML/CSS-анімацію «Людина задумує. AI допомагає втілити.». Репліки повертаються до цієї головної думки; анімацію можна повторити. Reduced motion враховано.

## Пошта перед запуском

Форма має три обов’язкові поля: автор, тема та зміст. **Реальне поштове надсилання ще потребує підключення Cloudflare Email Service і серверного обробника.** Поточна форма показує цей стан та не імітує доставку.

Приватної адреси отримувача й локальних налаштувань у репозиторії немає. Отримувач має задаватися тільки на сервері. Налаштування власного домену відкладено. Сайт опубліковано на наявному workers.dev; стан публікації наведено нижче.

## Перевірка

```powershell
python verify.py
```

Перевіряє цілісність усіх 56 файлів сайту за `site-manifest.json`. У браузері перевірено маршрут на ноутбуці й у мобільному режимі, повернення зі збереженням персоналізації, відеоперехід, форму, персонажів і повтор неонової анімації. Фізичні телефони й Safari не тестувалися.

Для наступного деплою є `deploy.ps1 -WorkerName <existing-worker-name>`. Перед увімкненням поштової доставки слід налаштувати її та перевірити фактичний лист.

Авторство та умови використання матеріалів визначені кореневим README цього репозиторію. Ця папка не змінює профільного маніфесту.
