# AINARIUM reusable examples

This is a deliberately prepared resource collection, not an extraction of arbitrary page content.

- `AINARIUM-neon-card.html`: reusable `.ainarium-card`, its scoped CSS, hover/focus behavior and editable copy.
- `AINARIUM-live-orb.html`: reusable `.ainarium-orb`, CSS floating animation and a keyboard-accessible click toggle.
- `AINARIUM-space-sky.html`: standalone CSS starfield `.ainarium-sky` with a translucent reading panel. This is an example style, not the course's illustrated image.

Every HTML file is self-contained and includes a Ukrainian usage note. No third-party libraries, network requests or external image files are required.

When the user asks to reuse an element:

1. Read only the supplied resource files that are relevant to the request.
2. Inspect the user's actual project before modifying it. Ask the user to identify the project if it is not available; the resource collection is not automatically the project root.
3. Transfer the requested markup, scoped styles and required behavior. Preserve accessibility and reduced-motion support.
4. Adapt the copy and links to the user's request. Do not invent profile data or paths.
5. Preserve existing project files and behavior. Explain what changed and how to verify it.

The browser may have downloaded only one example. Check which files are actually present before referring to other examples. The resource folder has no autonomous connection to Codex or Claude; the user must grant the desktop assistant access or supply these files.

## Public examples by description

Source: https://ainarium.com. When the user describes a component, open the site in an available internal or external browser and find the requested example. Inspect its appearance, behavior and available public source/resources. Reuse only the requested component in the actual project. If only the visible design is available, recreate it and explain that distinction. If the site or browser is unavailable, report that and ask for a direct link, screenshot or file; do not invent content. Browser-local personal photos and boards require an explicit export or attachment.
